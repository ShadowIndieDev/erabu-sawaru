# えらぶの窓 さわる2択（iPad）

「えらぶの窓」iPad版 0.1.10 を元にした、**別のアプリ**です。左右の2択だけを扱い、画面の左右どちらかの半分に**触れた瞬間**に、その側のカードを選びます。

指を細かく動かすのが難しい子どもでは、画面に触れたり撫でたりはできても、それがタップでなく拡大やページ送りとして読み取られ、カードを選べないことがありました。このアプリでは、触れ方を問わずに、最初に触れた位置の左右だけで選びます。

元の「えらぶの窓」（iPad版・Web版）は変えていません。保存する場所も別なので、同じiPadで両方を使えます。

## Web版（URLを開いて使う）

https://shadowindiedev.github.io/erabu-sawaru/

- iPadのSafariで開くと、すぐに使えます。Safariの「共有」→「ホーム画面に追加」で追加して開くと、アドレスの欄が消え、全画面で使えます。
- セット・写真・設定は、その端末のそのブラウザの中（IndexedDB）に保存します。送信はしません。利用の集計もしていません。ブラウザのデータを消すと消え、Safariで開いたものとホーム画面に追加したものでも保存は別になります。
- 読み上げはブラウザの日本語音声、画面を暗くしないのはScreen Wake Lock（使えるブラウザだけ）です。
- 画面の端からのスワイプは止められません。iPadの「アクセスガイド」を使ってください。

## iPadで起動する（Swift Playgroundsのアプリ）

1. `ErabuSawaru-playground-v<版>.zip` を、GoogleドライブなどでiPadに渡します。
2. iPadの「ファイル」アプリの「このiPad内」にZIPを保存し、タップして展開します。
3. 中の **ErabuSawaru-v<版>.swiftpm** を、Swift Playgroundsで開いて▶を押します（Package.swiftだけを開かず、.swiftpm全体を開いてください）。
4. 横向きで使います。最初は見本のセット（食べもの・動物）が入っています。

Swift Playgroundsで動かすプロジェクトです。App StoreやTestFlightで配るアプリではありません。

## 遊ぶ画面

- 画面の上の細い帯は**支援者用**です。帯より下なら、どこに触れても選択になります（問いかけの文字や、カードの外の余白も含みます）。
- 触れた瞬間に、触れた側を選びます。撫でる・押しつける・指を何本も置く、のどれでも選べます。決めるのは**最初に触れた指の位置だけ**で、後から置いた指や指の動きは見ません。
- 選んだ側は太い枠で囲み、反対側を薄くして、言葉を読み上げます。触れた場所には丸い輪が広がります。
- 選んだ後は「えらびなおす」まで選択を保ちます。次の質問へは自動では進みません。
- 拡大・スクロール・ページ送り・長押しのメニュー・ダブルタップでの拡大は起きないようにしています。

### 上の帯（支援者用）

| ボタン | 働き |
|---|---|
| えらびなおす | 選択を解除します |
| もういちど読む | 選んだ言葉を読みます。選ぶ前なら問いかけを読みます |
| 休む／再開する | 休んでいる間は、触れても選びません |
| ‹ › | 前・次の質問 |
| 左右を入れ替え | 左右のカードを入れ替えます（選択は解除） |
| 設定（長押し） | 1秒押し続けると、設定・使い方を開きます |

## 設定・使い方

- **セット**：使うセット・はじめる質問の切り替え、編集、新しいセット、読み込み。
- **真ん中の反応しない幅**：なし（標準）／細い／広い。真ん中に手が置かれやすいときに、幅の中では選ばないようにします。
- **選んだ後に、また触れたとき**：何もしない（標準）／選んだ言葉をもう一度読む（続けて触れても1.2秒に1回まで）。
- **絵の下に言葉を表示する**、**使っている間は画面を自動で暗くしない**（標準はどちらも入）、**読む速さ**。

### アプリでは止められないこと

画面の端からのスワイプ（ホームに戻る・コントロールセンター）は、1回目では移らないようにしていますが、完全には止められません。4本・5本の指のジェスチャも同じです。必要なときは、iPadの「設定」で次を使ってください（支援者がiPadで設定します）。

- 「アクセシビリティ」→「アクセスガイド」：このアプリから出ないようにできます。
- 「マルチタスクとジェスチャ」：4本・5本の指でのジェスチャを切ります。

## セットの編集

- 1つのセットに質問は50まで。質問ごとに、問いかけと、左右それぞれの言葉・読み上げる文（空なら言葉を読む）・絵を決めます。
- 絵は見本の8枚（りんご・バナナ・おにぎり・パン・いぬ・ねこ・うさぎ・ぞう）か写真です。写真はJPG・PNG・WebP（1枚15MBまで）で、アプリの中で長い辺1024 px以下に縮めて保存します。
- **GIF**も使えます。縮めると動きが消えるので、手を加えずにそのまま保存し、動くGIFは動いたまま表示します（1枚5MBまで）。点滅の激しいGIFは避けてください。GIFの絵を入れたセットは、元の「えらぶの窓」ではその絵が読めません（元のアプリはGIFを受け付けないため）。
- 質問の追加・削除・並べ替え、セットの書き出し・削除ができます。セットは50まで、保存全体は60MBまでです。

## 元の「えらぶの窓」とのセットの受け渡し

- 書き出したファイル（`.erabu.json`）は、元の「えらぶの窓」と同じ形式です。元のアプリ（iPad版・Web版）でも読めるはずですが、元のアプリで読み込む確認はまだしていません。
- 元のアプリのファイルも読めます。**3択・4択の質問は読み飛ばし**、読み飛ばした数を表示します。2択の質問がないセットは追加しません。
- 読み込んだセットには新しいIDが付くので、同じファイルを2回読むと、別のセットとして2つ増えます。

## 保存とプライバシー

- セット・写真・設定は、このアプリ専用の場所（Application Support の `ErabuSawaru`）に保存します。元の「えらぶの窓」の保存とは別です。
- ネットワークは使いません（画面の中の決まり `connect-src 'none'`）。利用の集計も送りません。読み上げはiPadの日本語音声（AVSpeechSynthesizer）です。
- カメラは、セットの編集で「写真を選ぶ」から写真を撮るときだけ使います（そのときにiPadが許可を求めます）。視線や顔の読み取りはしません。
- 保存したデータを読めないときは、上書きせずに止まります。アプリを削除せず、「読み込み直す」を試してください。

## 元のアプリから変えたこと

- 視線入力（カメラ・ARKit）と、その調整・記録の画面を外しました。
- 3択・4択を外し、左右の2択だけにしました。
- 選び方を「カードを押す」から「左右の半分に触れた瞬間」に変えました。
- 支援者の操作を上の帯にまとめ、設定は長押しで開くようにしました。
- 起動の確認画面（「選択画面を開く」）をなくし、すぐに選ぶ画面を出します。
- 休む、真ん中の反応しない幅、選んだ後に触れたら読み直す、画面を暗くしない、を足しました。

## 開発

```
python Tools/build.py
```

`Web/`（画面：logic.js・host.js・app.js・style.css・index.html）と `Native/`（Swift）から、`docs/`（Web版。GitHub Pagesで公開する一式）と `build/ErabuSawaru-v<版>.swiftpm`・`build/ErabuSawaru-playground-v<版>.zip` を作ります。版は `version.json`。

```
node --test Tests/logic.test.js
```

PCのブラウザでは `python -m http.server 8792 --bind 127.0.0.1 --directory docs` で開けます。Web版と同じ動きです。
